How it works

A three-step Retrieval-Augmented Generation pipeline: store, search, recommend.

01 / STORE

Embed employee skills

Each employee becomes a sentence like Employee Bob is qualified in: React…. Pinecone embeds it with llama-text-embed-v2.

02 / SEARCH

Search by meaning

The project scope is embedded the same way. Pinecone returns the closest profiles, so "reactive dashboard" finds React developers.

03 / RECOMMEND

Ask the LLM

The top matches and the scope go to Mistral, which picks the best fit and gives a short justification.

Employee skills→Pinecone index→Semantic search→Top-k matches→Mistral AI→Recommendation

Run it yourself

You need free API keys from Pinecone and Mistral.

git clone https://github.com/aditi27003/AI-Workforce-Matcher.git
cd AI-Workforce-Matcher
pip install -r requirements.txt
cp .env.example .env   # add your API keys
python vector_database.py "Set up CI/CD pipelines on AWS with Docker"
# 1. Open the notebook in Colab
# 2. Secrets panel → add MISTRAL_API_KEY and PINECONE_API_KEY
# 3. Runtime → Run all

🔒 API keys stay in your local .env or Colab Secrets and are never committed.
